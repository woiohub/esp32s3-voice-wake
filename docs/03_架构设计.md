> 版本 v0.3 · 对应固件 fw 0.5.0 / 上位机 host v0.7.2
>
> **本文是跨两端的总览。** 细节分别见：

## 1. 总体架构

```
┌─────────────────────────────┐          WiFi / TCP           ┌──────────────────────────────┐
│  下位机 ESP32-S3-CAM        │  ◄──────── 上行语音 PCM ─────── │  上位机 PC（Python）          │
│  · INMP441  (I2S 输入)      │  ──────── 下行 TTS PCM ───────► │  · TCP 服务端                  │
│  · ESP-SR AFE 唤醒/打断      │  ◄──────── 控制/配置 JSON ────► │  · STT → LLM → TTS 管线        │
│  · MAX98357 (I2S 输出)      │                                 │  · PySide6 GUI                 │
└─────────────────────────────┘                                 └──────────────────────────────┘
```

## 2. 下位机结构（components 多组件，符合乐鑫官方推荐）

核心入口在 `main/`，各功能模块拆分为 `components/` 下独立组件（每个组件含自己的 `CMakeLists.txt`，头文件统一放 `include/`）：

```
firmware/
├── CMakeLists.txt / sdkconfig.defaults / partitions.csv
├── main/                          # 入口组件
│   ├── app_main.c                 # 按序初始化各组件
│   ├── CMakeLists.txt             # REQUIRES vw_audio vw_config vw_voice
│   └── Kconfig.projbuild          # 全部 VW_* 可调配置（menuconfig 图形化）
└── components/
    ├── vw_utils/     # 工具层：统一日志 + 错误码
    ├── vw_audio/     # 驱动层：I2S 麦克风 + 功放
    ├── vw_config/    # 服务层：NVS 配置
    ├── vw_wakeword/  # 服务层：ESP-SR AFE（idf_component.yml 声明 esp-sr 依赖）
    ├── vw_comm/      # 通信层：帧协议 / TCP 客户端 / WiFi
    └── vw_voice/     # 业务层：会话状态机、命令处理、端点/打断
```

### 组件依赖关系

| 组件 | REQUIRES | PRIV_REQUIRES |
|------|----------|---------------|
| vw_utils | — | — |
| vw_audio | driver | — |
| vw_config | — | nvs |
| vw_wakeword | vw_utils | esp-sr |
| vw_comm | vw_utils | esp_wifi esp_netif esp_event nvs lwip esp_timer |
| vw_voice | vw_audio vw_config vw_comm vw_wakeword vw_utils | json esp_timer |
| main | vw_audio vw_config vw_voice | — |

依赖方向：main → vw_voice → {vw_audio, vw_config, vw_comm, vw_wakeword} → vw_utils；底层不反向依赖上层。新增功能模块 = 在 `components/` 下新建组件并声明依赖，无需改动现有组件。新增可配置项统一加到 `main/Kconfig.projbuild`，代码用 `CONFIG_VW_*` 读取，`idf.py menuconfig` 图形化调整。

### 模块清单

| 文件 | 说明 |
|------|------|
| `main/app_main.c` | 入口：NVS → I2S → 业务服务 |
| `components/vw_voice/` | 会话状态机、VAD 端点、音量、控制命令、barge-in |
| `components/vw_audio/` | INMP441(RX) + MAX98357(TX) I2S 封装 |
| `components/vw_wakeword/` | ESP-SR AFE 封装（WakeNet + AEC + VAD） |
| `components/vw_config/` | NVS 配置读写 |
| `components/vw_comm/` | 帧协议 + TCP 客户端（重连/心跳）+ WiFi/AP 配网 |
| `components/vw_utils/` | 统一日志 + 错误码表 |

### 依赖规则（扩展约束）

- 上层可调用下层，下层不得反向依赖上层（组件依赖表为准）。
- 新增模块时，在 `components/` 下新建组件并声明依赖；跨层能力通过 `vw_utils` 的 `VW_LOG_E(tag, code, ...)` 输出带错误码的日志。
- 新增可配置项统一加到 `main/Kconfig.projbuild`，代码用 `CONFIG_VW_*` 读取。

## 3. 统一日志规范

- **TAG 命名**：`<层>:<模块>`，如 `drv:i2s`、`srv:wake`、`comm:net`、`app:voice`、`main`。
- **错误日志**：一律用 `VW_LOG_E(tag, 错误码, "描述 %d", ...)`，自动附加 `[0x%04X:错误码名]`。
- **错误码分层**：0x01xx 通用、0x10xx 驱动、0x20xx 服务、0x30xx 通信、0x40xx 业务（见 `vw_err_t`）。
- **时间戳**：由 ESP_LOG 底层统一提供。

上位机对应：`voice_assistant/log.py` 提供 `init_logging()` / `get_logger()`，模块用 `__name__` 作标识，格式与下位机对齐（`时间戳 [模块] 级别`），并支持滚动文件落盘。

## 4. 上位机结构（host/）

| 文件 | 职责 |
|------|------|
| `main.py` | 入口：日志 → 配置 → 引擎自检 → TCP 服务 + GUI |
| `voice_assistant/log.py` | 统一日志（控制台 + `logs/` 滚动文件） |
| `voice_assistant/config.py` | 配置模型（dataclass）+ JSON 读写 + provider 预设 |
| `voice_assistant/protocol.py` | 帧协议（与固件 `net_proto.c` 字节级对齐） |
| `voice_assistant/network.py` | asyncio TCP 服务端 + `DeviceConnection` |
| `voice_assistant/pipeline.py` | 会话编排 + 控制命令 + ACK + 下发节奏 + 回调事件 |
| `voice_assistant/stt.py` / `llm.py` / `tts.py` | 三个引擎封装（接口同构，便于替换） |
| `voice_assistant/model_download.py` | 模型缺失检测与一键下载 |
| `voice_assistant/gui/theme.py` | 颜色/字号/间距 token + QSS（唯一颜色来源） |
| `voice_assistant/gui/icons.py` | 内嵌 SVG → QPixmap/QIcon |
| `voice_assistant/gui/bridge.py` | pipeline 回调 → Qt Signal（跨线程排队） |
| `voice_assistant/gui/tasks.py` | `run_task`：QThreadPool 封装，耗时操作入口 |
| `voice_assistant/gui/main_window.py` | 顶栏 / 导航 / 页面栈 / 右侧栏 / 状态栏 / 快捷键 |
| `voice_assistant/gui/pages/` | session / device / model / log 四页 |
| `voice_assistant/gui/widgets/` | chat_bubble / stage_timeline / level_meter / status_pill / model_status_card / toast / setup_checklist |

## 5. 扩展点

1. **新增唤醒词/命令**：改 `CONFIG_VW_SR_WAKENET_NAME` 后重新 `idf.py flash`（运行期不可换），无需改代码。
2. **新增控制命令**：在 `voice_service.c::handle_control` 增加分支即可，协议已框架化。
3. **新增上位机引擎**：实现 `stt/llm/tts` 同款接口（`preload` / `transcribe|reply|synthesize`），在 `main.py` 替换实例。
4. **新增硬件外设**：在 `components/` 下新建组件并声明依赖，由业务层调用（不要放回 `main/`）。
5. **新增 GUI 页面**：`gui/pages/` 新建 Page，在 `main_window._build` 加进 `QStackedWidget` 并在 `_NAV` 加一项。
