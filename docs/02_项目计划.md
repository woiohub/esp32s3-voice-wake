# 项目计划

> 版本 v0.1 · 状态：待评审
> 关联文档：`01_接口设计.md`、`../README.md`

## 0. 已确认方案速览

| 决策点 | 结论 |
|--------|------|
| 传输 | WiFi STA + TCP 长连接（设备作客户端），**蓝牙（BLE）配网兜底** |
| 音频 | PCM 16kHz/16bit/单声道，20ms 分帧 |
| 唤醒词 | ESP-SR WakeNet，先用内置「Hi 乐鑫」，预留自定义 |
| 打断 | 一期集成 AEC 回声消除，支持播报中打断 |
| STT | faster-whisper tiny/base（本地） |
| LLM | GLM / Qwen（OpenAI 兼容接口） |
| TTS | Piper（本地轻量） |
| GUI | PySide6 桌面 |
| 摄像头 | 不启用，释放 GPIO |

## 1. 里程碑（M0–M7）

| 里程碑 | 目标 | 出口标准 |
|--------|------|----------|
| **M0 环境与骨架** | 搭好 ESP-IDF 与 Python 环境、目录骨架 | 下位机可编译空固件烧录、上位机可运行空 GUI |
| **M1 下位机音频链路** | I2S 采集 + 功放播放 | 麦克风录音、扬声器播放测试音频均正常 |
| **M2 唤醒词** | ESP-SR WakeNet 集成 | 唤醒词命中点亮 LED / 串口打印，误唤醒可接受 |
| **M3 通信链路** | TCP 帧协议双向打通 | 音频可实时上行、TTS 音频可下行播放 |
| **M4 上位机管线** | STT→LLM→TTS 跑通 | 语音问题→文字→精简回复→语音，端到端可用 |
| **M5 GUI 与配置** | PySide6 界面 + 参数下发 | 界面可改音量/WiFi/IP，设备实时生效并持久化 |
| **M6 AEC 与优化** | 打断、延迟、稳定性 | 播报中可打断；端到端延迟 <2s；7×24 稳定运行 |
| **M7 联调与交付** | 整机联调、文档、打包 | 交付可运行固件 + 上位机程序 + 使用说明 |

## 3. 风险清单

| 风险 | 影响 | 应对 |
|------|------|------|
| ESP32-S3-CAM 引脚与推荐默认不符 | M1 阻塞 | T4 尽早核对板型原理图，引脚走 Kconfig |
| ESP-SR 与 IDF 版本不兼容 | M2 阻塞 | 锁定 ESP-SR 与 IDF 版本组合，先跑官方示例 |
| AEC 在 S3 上 CPU 吃紧/回声残留 | M6 质量 | 用数字参考信号；必要时降采样/降帧率或退化为「播报期不采集」 |
| STT 模型加载慢/显存不足（PC） | M4 性能 | 用 tiny/base，预加载常驻内存 |
| LLM API 延迟抖动 | M4 延迟 | 短 prompt + 限 max_tokens；必要时流式输出边生成边 TTS |
| 网络抖动导致播放卡顿 | M6 稳定性 | 下位机 jitter buffer（20–60ms）+ 序号检测丢帧 |
