# 上位机配置说明（config.json / 模型 / 环境变量）

> 适用版本：**host v0.7.2**
> 配置加载实现：`voice_assistant/config.py`

`host/config.json` 首次启动时自动生成（`ensure_config_file()`），
之后**所有可调项都在这个文件里**，改完重启生效（部分项在界面里保存会立即写回）。

```bash
python -c "import json;print(json.dumps(json.load(open('config.json')),ensure_ascii=False,indent=2))"
```

---

## 1. 完整骨架与默认值

```json
{
  "audio":   { "sample_rate": 16000, "bits": 16, "channels": 1, "frame_ms": 20 },
  "stt": {
    "model_size": "tiny",
    "model_dir": "",
    "auto_download": false,
    "hf_endpoint": "https://hf-mirror.com",
    "download_root": "models/whisper",
    "hf_home": "models/hf_home",
    "language": "zh",
    "device": "cpu",
    "compute_type": "int8",
    "beam_size": 5
  },
  "llm": {
    "provider": "glm",
    "base_url": "https://open.bigmodel.cn/api/paas/v4",
    "api_key": "",
    "model": "glm-4-flash",
    "max_tokens": 128,
    "temperature": 0.7,
    "timeout": 30.0,
    "system_prompt": "你是语音助手，用简洁口语回答，控制在1-2句话以内。"
  },
  "tts": { "model_path": "models/piper/zh_CN-huayan-medium.onnx", "speaker": 0, "length_scale": 1.0 },
  "network": { "host": "0.0.0.0", "port": 8888 },
  "device": {
    "volume": 60, "wake_enable": true,
    "ack_enable": true, "ack_text": "在的",
    "host_ip": "", "host_port": 8888,
    "wifi_ssid": "", "wifi_password": ""
  }
}
```

> 首次生成的模板里 `stt.model_size` 是 `tiny`；若你手动放了 `small` 模型，
> 记得把 `model_size` 与 `model_dir` 一起改成 `small`。

---

## 2. `audio` —— 音频链路参数

| 键 | 默认 | 说明 |
|---|---|---|
| `sample_rate` | 16000 | **必须与下位机 `CONFIG_VW_SAMPLE_RATE` 一致** |
| `bits` | 16 | 固定 16，改了不起作用（协议层写死 int16） |
| `channels` | 1 | 固定单声道 |
| `frame_ms` | 20 | 分帧时长，需与下位机 `CONFIG_VW_FRAME_MS` 一致 |

> 改了 `sample_rate` 而没改固件 = 设备按自己的时钟采集，上位机当另一个速率解读，
> 结果是语速/音调整体错位。这是一条**隐性契约**。

---

## 3. `stt` —— 本地语音识别（faster-whisper）

| 键 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `model_size` | `tiny` | tiny/base/small/medium | 只在自动下载时决定拉哪个；手动放置时仅作显示 |
| `model_dir` | `""` | 路径 | **本地模型目录，优先使用**。必须指到含 `model.bin` 的那一层 |
| `auto_download` | `false` | bool | 找不到模型时是否允许自动下载。**默认关**，避免无网时卡住 |
| `hf_endpoint` | `https://hf-mirror.com` | URL | 写进 `HF_ENDPOINT`，国内必须用镜像 |
| `download_root` | `models/whisper` | 路径 | 自动下载的落地目录（相对 `host/`） |
| `hf_home` | `models/hf_home` | 路径 | HuggingFace 缓存根，放项目内避开用户目录权限问题 |
| `language` | `zh` | zh/en/auto | 传给 whisper；`auto` 会自动检测但更慢 |
| `device` | `cpu` | cpu/cuda | 有 NVIDIA 显卡可改 `cuda`（需装 CUDA 版依赖） |
| `compute_type` | `int8` | int8/float16/float32 | CPU 用 `int8` 最快；GPU 可用 `float16` |
| `beam_size` | 5 | 1~10 | 越大越准越慢；`1` 接近贪心，最快 |

### 3.1 模型放置（默认路径，推荐）

```
host/models/whisper/faster-whisper-small/
├── model.bin            ← 必需
├── config.json          ← 必需
├── tokenizer.json       ← 必需
├── vocabulary.txt
└── ...
```

`config.json` 里对应：

```json
"stt": { "model_size": "small", "model_dir": "models/whisper/faster-whisper-small" }
```

三个必需文件缺任何一个，启动自检就会报 `【STT 未就绪】…缺少：…`。

### 3.2 速度对照（本机 CPU 实测）

| 模型 | 加载 | 1.5s 音频推理 | 备注 |
|---|---|---|---|
| tiny | ~0.5s | ~0.1s | 准确率一般，适合低配机 |
| base | ~0.8s | ~0.2s | 折中 |
| **small** | ~1.3s | ~0.31s | 本项目在用的配置 |
| medium | ~3s | ~0.8s | 端到端会明显变慢 |

> 端到端超过 5s 时，第一件事就是把 `model_size` / `model_dir` 换到 `tiny`。

### 3.3 `auto_download` 的三种状态

| `auto_download` | `model_dir` | 行为 |
|---|---|---|
| `false`（默认） | 填了且有效 | 直接用本地模型，**完全不联网** |
| `false` | 空或无效 | `preload()` 直接报错，提示「可点一键下载模型」 |
| `true` | 空或无效 | 启动时从 `hf_endpoint` 拉取到 `download_root` |

无论哪种，界面「模型」页的**「一键下载模型」**按钮都可以显式触发下载
（会弹窗告知体积，只下缺失的部分）。

## 4. `llm` —— 大模型

| 键 | 默认 | 说明 |
|---|---|---|
| `provider` | `glm` | `glm` / `qwen`，决定界面里切换时的预设值 |
| `base_url` | GLM 地址 | OpenAI 兼容端点，见下表 |
| `api_key` | `""` | **必填**。为空时启动自检就报未就绪 |
| `model` | `glm-4-flash` | 模型名，须与账号开通的一致 |
| `max_tokens` | 128 | 语音助手回复要短，128 足够；调大会拖慢 TTS |
| `temperature` | 0.7 | 0~2 |
| `timeout` | 30.0 | 秒 |
| `system_prompt` | 「你是语音助手，用简洁口语回答…」 | 直接影响回复长度，建议保持 1~2 句 |

### 4.1 两家预设

| provider | `base_url` | 推荐 `model` |
|---|---|---|
| `glm`（智谱） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`（有免费额度，最快） |
| `qwen`（阿里） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-turbo` |

在界面「模型」页切换 provider 时，`base_url` 与 `model` 会自动带出预设值
（`config.py::PROVIDER_PRESETS`）。

### 4.2 为什么 `max_tokens` 要小

TTS 是逐字合成的，回复越长音频越长、上报时间也越长。语音场景下
"一句话答完"体验最好，所以默认 128 并把要求写进 `system_prompt`。

## 5. `tts` —— 本地语音合成（Piper）

| 键 | 默认 | 说明 |
|---|---|---|
| `model_path` | `models/piper/zh_CN-huayan-medium.onnx` | 指到 **.onnx 文件本身**，不是目录 |
| `speaker` | 0 | 多说话人模型才有意义，单说话人填 0 |
| `length_scale` | 1.0 | >1 更慢，<1 更快。界面「语速(时长×)」对应它 |

**目录里必须有两个文件**：

```
host/models/piper/zh_CN-huayan-medium.onnx
host/models/piper/zh_CN-huayan-medium.onnx.json     ← 缺了报 config not found
```

采样率不用配：模型输出 22050Hz，`tts.py` 会**自动重采样**到 `audio.sample_rate`。
启动日志确认：

```
INFO: Piper 输出 22050 Hz，将重采样到 16000 Hz
```

## 6. `network` —— TCP 监听

| 键 | 默认 | 说明 |
|---|---|---|
| `host` | `0.0.0.0` | 必须是 `0.0.0.0` 才能接受外部设备；`127.0.0.1` 只收本机 |
| `port` | 8888 | **必须与下位机 `CONFIG_VW_TCP_PORT` 一致** |

---

## 7. `device` —— 下发给下位机的项

分两类：**下发到设备**的和**只在上位机用**的。

| 键 | 默认 | 是否下发 | 说明 |
|---|---|---|---|
| `volume` | 60 | ✅ | 设备播放音量 0~100（设备侧软件缩放） |
| `wake_enable` | true | ✅ | 唤醒开关 |
| `ack_enable` | true | ✅ | 唤醒后是否先播回复词、播完再采集 |
| `ack_text` | `在的` | ❌ | **只在上位机合成**，不下发（设备没有 TTS） |
| `host_ip` | `""` | ✅ | 上位机 IP，设备用它连过来 |
| `host_port` | 8888 | ✅ | 上位机端口 |
| `wifi_ssid` | `""` | ✅ | 设备 WiFi（通过 `wifi.set` 下发，设备重启生效） |
| `wifi_password` | `""` | ✅ | 同上 |

### 7.1 `host_ip` 填什么

启动日志会直接告诉你：

```
INFO: 本机 IP=172.17.253.195，下位机 host.ip 应填这个地址（当前配置 host_ip=）
```

填这个 IP（**不是** `127.0.0.1`，也不是设备 IP），然后在设备页点「下发配置」。
下发后设备会重启生效。

### 7.2 回复词链路

```
config.json → device.ack_text ──► 上位机 TTS 合成 ──► AUDIO_DOWN ──► 设备播放
config.json → device.ack_enable ─► config.set ──► 设备 NVS(ack_en) ──► 是否等待
```

两侧都要开：设备不等待 → 上位机发的回复词会和用户语音撞在一起；
上位机不合成 → 设备白等 4s（有超时兜底，功能不坏但少了回复词）。

## 8. `ui_state.json`（GUI 偏好）

与业务配置**分开存**，因为里面没有机密、可以随手删（删了就用默认值）：

| 键 | 说明 |
|---|---|
| `w` / `h` | 窗口宽高（关闭时保存） |
| `page` | 上次停留的页面索引 0~3 |
| `right_collapsed` | 右侧栏是否折叠（`Ctrl+R` 切换） |
| `theme` | `dark` / `light` |

## 9. 环境变量

`stt.py` 会在 **import faster_whisper 之前**写入这些（值为 `setdefault`，
已存在的环境变量优先）：

| 变量 | 值 | 作用 |
|---|---|---|
| `HF_ENDPOINT` | `stt.hf_endpoint` | 换镜像源，国内必须 |
| `HF_HUB_DISABLE_XET` | `1` | 关掉 xet 后端，绕开 `os error 5 拒绝访问` |
| `HF_HOME` | `stt.hf_home`（转绝对路径） | 缓存目录放项目内 |

想在命令行临时覆盖：

```powershell
$env:HF_ENDPOINT="https://hf-mirror.com"
$env:HF_HUB_DISABLE_XET="1"
python main.py
```

## 10. 配置优先级

```
Kconfig / 代码默认值（config.py 的 dataclass 默认值）
        │
config.json 里存在的键（只覆盖同名键，缺的保留默认）
        │
界面上的保存操作（写回 config.json）
```

因此：

- 删掉 `config.json` 里某一项 → 自动回到代码默认值，不会报错；
- 多写不认识的键 → 忽略（`load_config` 只认 dataclass 里有的字段）；
- 手改 `config.json` 后**必须重启**才生效（`MainWindow.closeEvent` 会把内存里的值写回，
  所以运行期手改文件可能被覆盖）。

## 11. 配置检查清单

```bash
cd host
# 1) 关键字段
python -c "
import json; c=json.load(open('config.json'))
print('port   ', c['network']['port'])
print('rate   ', c['audio']['sample_rate'])
print('stt    ', c['stt']['model_size'], c['stt']['model_dir'], 'auto_dl=', c['stt']['auto_download'])
print('llm    ', c['llm']['provider'], c['llm']['model'], 'key=', (c['llm']['api_key'] or '')[:6] + '****')
print('tts    ', c['tts']['model_path'])
print('device ', c['device']['host_ip'], c['device']['host_port'], 'ack=', c['device']['ack_enable'], c['device']['ack_text'])
"

# 2) 模型文件
ls models/whisper/faster-whisper-*/model.bin
ls models/piper/*.onnx models/piper/*.onnx.json
```

| 检查项 | 期望 |
|---|---|
| `network.port` | 与固件 `CONFIG_VW_TCP_PORT` 相同 |
| `audio.sample_rate` / `frame_ms` | 与固件 `CONFIG_VW_SAMPLE_RATE` / `VW_FRAME_MS` 相同 |
| `stt.model_dir` | 含 `model.bin` 的那一层 |
| `stt.auto_download` | 保持 `false`（想省事才开） |
| `llm.api_key` | 非空，且账号有该模型权限 |
| `tts.model_path` | `.onnx` 与 `.onnx.json` 都在 |
| `device.host_ip` | 本机局域网 IP（启动日志会打印） |
